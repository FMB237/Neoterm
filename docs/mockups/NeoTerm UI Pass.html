NeoTerm — global UI pass

The terminal works; this is about how it looks and feels. Every value below is taken from the current implementation (config.rs theme tokens, renderer.rs geometry), so the proposal is not a vibe — it is a diff you can read. The direction: quiet chrome. Chrome appears when it is relevant and fades when it is not. Nothing permanent, nothing decorative.

02The tab strip, in all four states

The strip is the only permanent chrome in the app, so it carries the most weight per pixel. Four states, one rule: the active tab is the only loud thing; everything else is one step back.

03The cursor — the one real bug in the set

Today the cursor is a █ glyph written over the cell, so the character you are typing on top of disappears. That is not a taste question; it is a fidelity bug. The fix is to draw the block in the background pass and keep the glyph on top — the renderer already has a quad pass and the glyph is shaped independently, so this costs one extra quad per cursor cell.

04What changes, token by token

Nothing here is a new color system. Everything reuses the Tokyo Night pack that already ships.

ElementTokenValue & rationale
Strip background theme.background #1a1b26 — unchanged. The strip stays seamless with the body.
Strip separator new: tab_bar_border #2b2c3d — one hairline under the strip. Makes the region legible without adding a band.
Tab index badge new: tab_index_fg #4a5170 — one step dimmer than the inactive label, so the number never competes with the title.
Active tab title theme.tab_active_fg #7aa2f7 — unchanged, plus the existing 2 px accent underline.
Inactive tab title theme.tab_inactive_fg #565f89 — unchanged.
Close mark theme.tab_close_fg #737aa2 — hidden at rest, full opacity on hover. × when the font measures it as one cell, else ASCII x.
Focused pane outline new: focus_outline accent at 38 % — 1 px inset by 1 px. Unfocused panes recede to 62 %.
Cursor block theme.cursor cursor color at 42 % behind the glyph — the character underneath stays readable.
Toast surface theme.tab_active_bg #292e42 — the one reserved field in the theme finally gets a job. The pill sits in the body's bottom-right corner, not in the strip: the strip is often full of long titles.
Timing — hover fade 120 ms · toast hold 1.4 s · focus outline instant (no animation on a focus cue).

05The issue list this pass closes

bug

The cursor hides the character under it

Today the cursor is a glyph that replaces the cell content. Fix draw the block in the background pass, keep the glyph in the text pass. Same drift-free guarantee, one extra quad.

usability

Focus is nearly invisible in a split

Today the only difference is which cursor blinks — gone in a screenshot, easy to miss at speed. Fix outline the focused pane, recede the others.

feedback

Copy and paste happen silently

Today Ctrl+Shift+C or a drag-select does something you cannot see. Fix a short toast in the strip: copied · 42 chars.

affordance

No hover state anywhere

Today the pointer can sit on a tab with zero feedback. Fix hover reveals the close mark and lifts the label one step. 120 ms, no popovers.

taste

The tab label reads like a debug string

Today [1:bruce@host:~/projects x] — index, colon, brackets, ASCII x. Fix a dim index badge, a clean title, a close mark revealed on hover. The hit targets stay cell-accurate: the label length is still counted in cells, so nothing shifts.

taste

The strip is not legible as a region

Today seamless means the top of the window reads as more text. Fix one hairline under the strip — the cheapest possible separation, and it keeps the Ghostty feel.

Not in this pass: search UI, scroll position, session restore, window transparency. Those are features, not polish — they belong to the next milestone, not to a UI pass.
